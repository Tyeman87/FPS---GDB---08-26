1. QUICK START GUIDE
----------------------------------------------------------------------------
- Open your Unity scene.
- Go to Assets -> Polykebap -> Doors -> Prefabs folder.
- Drag-and-drop any door asset right into your game world.

2. TROUBLESHOOTING
----------------------------------------------------------------------------
Pink color problem:
The color pink is an indicator of your project is using a different Render Pipeline than URP.

If your project is Built-in Render Pipeline
You need to manually change the material shaders from Universal Render Pipeline/Lit back to Standard.
You can select all your asset's materials in the Project window, go to the Inspector, click the Shader dropdown at the top, and select Standard.

If your project is HDRP
You can select the materials and go to Edit > Rendering > Materials > Convert Selected Built-in/URP Materials to HDRP (or use Window > Rendering > Render Pipeline Converter).
